🧪 Testes de Regressão — Urban Routes

Projeto prático de Quality Assurance (QA) focado na execução de testes de regressão em uma aplicação web, buscando identificar falhas e garantir a estabilidade das funcionalidades existentes.

⸻

🎯 Objetivo

Executar testes de regressão na aplicação Urban Routes, validando o comportamento das funcionalidades e identificando possíveis problemas após alterações no sistema.

Durante o projeto, também foram realizados registro, documentação e rastreamento dos bugs encontrados.

⸻

📊 Resultados

🧪 Testes (24) 	✅ Aprovados (17)	❌ Reprovados (7)	🐞 Bugs (7)


📈 Taxa de aprovação

70,8% dos casos de teste foram aprovados.

⸻

🔍 Processo de QA

O projeto envolveu diferentes etapas do processo de testes:

Planejamento → Execução → Validação → Identificação de falhas → Registro de bugs → Rastreamento

⸻

🛠️ Atividades realizadas

* 📝 Planejamento e execução de casos de teste
* 🔄 Execução de testes de regressão
* 🧪 Execução de testes funcionais
* 🔎 Validação dos resultados esperados x obtidos
* 🐞 Identificação e documentação de bugs
* 📌 Registro e rastreamento de defeitos
* 🚦 Classificação de bugs por prioridade
* 📊 Análise dos resultados dos testes

⸻

📚 Conhecimentos aplicados

Durante o desenvolvimento deste projeto foram praticados conceitos de:

* Testes de regressão
* Testes funcionais
* Casos de teste
* Documentação de testes
* Identificação de defeitos
* Reporte e rastreamento de bugs
* Priorização de problemas
* Análise de resultados
* Validação de requisitos

⸻

💡 O que este projeto demonstra?

Este projeto demonstra a aplicação prática de conceitos de QA, desde a execução dos casos de teste até a identificação, documentação e rastreamento de defeitos.

O objetivo foi simular uma rotina de testes próxima à realidade de um ambiente profissional, mantendo os resultados organizados e rastreáveis.
